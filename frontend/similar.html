用户相似度检索

基于用户邻域结构计算其与全图其他用户的结构相似度：Jaccard（邻域交并比）与 Adamic-Adar（共同好友按度数对数去偏），按相似度从高到低稳定排序。

相似用户列表
指标口径
Jaccard = |N(u) ∩ N(v)| / |N(u) ∪ N(v)|，取值 0–1，越接近 1 表示两位用户的好友集合越重合。
Adamic-Adar = Σz∈共同好友 1 / log(deg(z))，共同好友本身越“小众”（度数越低）贡献越大，枢纽节点被降权。
排序规则：Jaccard 降序 → Adamic-Adar 降序 → 用户 ID 升序，保证同一图数据下结果稳定、可复现。
